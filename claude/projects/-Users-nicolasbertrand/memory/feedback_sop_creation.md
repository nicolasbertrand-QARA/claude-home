When creating SOP templates in the Method & Templates Notion database:

1. Each SOP gets its own page (Type="SOP") with its own inline database, matching the "SOP Managing Documents & Records" pattern.
2. Include a "Section #" number property in each database for explicit ordering.
3. Views must be sorted by "Section #" ASC with WRAP CELLS true.
4. Tag SOPs with "CLAUDE" in the Texte field.
5. Sections must be ordered as they would appear in the final SOP: Purpose & Scope first, then Definitions, then process sections in chronological order.
6. Draft Paragraphs must be actionable procedures (not standard paraphrases), with highlighted placeholders for client customization.
7. Check Points must be questions, not instructions.
8. Custom Edits must provide multi-scenario adaptation guidance.
9. Target profile: SaaS MDSW startup (cloud, agile, Git, CI/CD).

**Why:** User was dissatisfied with previous GENERATED SOPs that were too abstract and just paraphrased standards. The new approach writes like an experienced QARA consultant.

**How to apply:** Use this workflow for all future SOP template creation in this Notion workspace.
