When the user provides source materials (Google Drive links, slide decks, tech docs, internal documents) and I cannot access them (404, permission denied, link broken), I MUST stop and ask the user to grant access or share another way. Do NOT pursue the task using public knowledge, assumptions, or partial information.

**Why:** The user shared those specific materials because they are critical to the work. Proceeding without them produces a deliverable based on guesses, which wastes the user's time and undermines trust in the output. The user explicitly flagged this as "not acceptable."

**How to apply:** As soon as a provided URL/file returns 404, permission denied, or empty, surface the blocker immediately and offer concrete unblock paths (re-share with my email, drop in accessible folder, export to PDF locally). Wait for confirmation before continuing. This applies even if I think I have enough public context to make progress.
